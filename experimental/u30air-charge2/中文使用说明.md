# U30 Air 完整固件包 v2026.10.15-charge2

仅支持 ZTE U30 Air。基于上游 v2026.10.15，系统为 OpenWrt 25.12.5 LuCI，内核为 `7.2.9-u30air-charge2`，含全部 379 个匹配模块和启动 ramdisk。

合入外部供电 Host、分线器下充电识别、RTL8153 转接网卡、WiFi 永久 MAC 修复、0.1% 电量显示及受条件约束的容量学习。保留原厂温度/充电保护，OTG 升压关闭，Host 手动开启。

## 安装

解压完整 ZIP，准备 adb、Windows tar、Python 3.8+ 及该 Python 的 lz4 模块。设备从已 root 的 Android 槽 A 启动，并通过 USB 数据线直连电脑，在解压目录打开 PowerShell。

```powershell
# 只校验本地资产，不访问设备
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-u30air-host.ps1 -VerifyOnly
# 设备只读预检
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-u30air-host.ps1 -Check
# 实际安装，在提示中选择 update 或 wipe 并确认
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-u30air-host.ps1
```

入口固定 U30 Air / OpenWrt LuCI / 7.2 模式，校验本地资产，禁用源码自动更新，不下载替代固件或自动安装依赖。设备专属启动镜像在安装时读取目标设备的原厂数据生成，专属 WiFi/基带文件从目标设备提取。本包没有你的密码、无线配置、设备启动备份或基带提取文件。

wipe 会重建所选 Linux rootfs，清除其设置和数据，不是安全擦除；安装前自行备份需要保留的数据。安装器保留设备、存储布局和分区备份检查。**这是完整安装压缩包，不是通用 sysupgrade 镜像，不要在 LuCI 通用刷固件页面直接上传 ZIP。** 回退边界见 ROLLBACK.md。

## Host 和验证范围

连接有效外部供电，执行 `mu300-usb status`，再执行 `mu300-usb host`。网卡枚举后在 LuCI USB 网卡页面加入 LAN。Host 不会自动把新网卡加入网桥。

包内相同 charge2 内核已经在一台 U30 Air 安装启动，并通过充电上限、外部供电 Host/RJ45 网卡验证；WiFi 认证及无线访问 LuCI 在此前 charge1 版本验证，charge2 保留相同修复。此前 charge1 充电修复的 15 次连续净充电采样平均 4.75W，后续读数约 3.1–4.9W。LuCI 数值是电池净功率，不是充电器侧功率。新组装的完整 rootfs/ZIP 通过离线校验，尚未重新执行 wipe 安装。

全区间电量精度、完整容量学习周期、长时间稳定性及其他型号分线器的兼容性尚未验证。0.1% 是显示分辨率，不代表误差只有 0.1%。系统 → 电源支持 0–100% 整数充电上限：0% 持续暂停电池充电，保留外部供电和 Host 网卡；100% 使用原厂充电策略；1–99% 达到上限暂停，下降 5 个百分点恢复，恢复阈值最低为 0%。约 10 秒内应用，设置持久保存；新安装默认 100%。已实测 0% 暂停、100% 恢复和 80% 上限暂停时网卡保持在线。自然放电到恢复阈值尚未实测。

已知问题：遍历读取 `/sys/kernel/debug/regmap/*/registers` 可能访问不安全的时钟控制器寄存器并导致 panic。本包尚未修复这个调试接口；诊断使用已有 power_supply、Type-C 和 mu300-usb 状态接口。

发布时可以上传完整 ZIP、ZIP 对应 SHA256SUMS 文件及 RELEASE-NOTES.md。release 子目录还提供单独内核/rootfs 资产及其 SHA256SUMS，供明确了解匹配关系的维护者使用。
