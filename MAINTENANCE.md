# Maintenance scope

This fork is initially maintained for the OpenWrt system layer only. Kernel, bootloader, Android vendor components, and device-driver changes are outside the current maintenance scope.

## Hardware and verification

- Maintainer-tested device: Not yet recorded. Add the exact model after a real test; upstream support does not count as a test by this maintainer.
- Build, installation, boot, networking, Wi-Fi, and mobile modem behavior: Not yet verified by this maintainer.
- Until these checks are completed, this fork makes no claim of maintainer-verified OpenWrt support on any device.

The upstream README, credits, and license are retained.

# 维护范围

本分支目前只维护 OpenWrt 系统层。内核、引导程序、Android 厂商组件和设备驱动暂不在维护范围内。

## 设备与验证

- 维护者实测设备：尚未记录。完成实机测试后再填写具体型号；上游已支持不等于维护者本人已测试。
- 构建、安装、启动、网络、Wi-Fi 和移动网络功能：维护者尚未验证。
- 完成这些检查前，本分支不宣称任何设备已通过维护者实测。

保留上游 README、署名和许可证。
